### Descripción del proyecto

El proyecto consiste en el desarrollo de un **formulario web para registrar devoluciones de productos**. Su objetivo es facilitar la captura y organización de la información relacionada con los productos que son devueltos.

El formulario permite ingresar datos como el **nombre del producto, cantidad, fecha de devolución, motivo de la devolución y observaciones adicionales**. También cuenta con botones para registrar la devolución y limpiar los datos ingresados.

El proyecto fue desarrollado utilizando **HTML**, aplicando elementos como formularios, campos de texto, campos numéricos, selección de opciones, área de texto y botones, con el propósito de crear una interfaz sencilla y funcional para la gestión de devoluciones.
